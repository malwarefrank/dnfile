========
Examples
========

The repository ships with runnable examples under ``examples/``. They show how
to inspect common pieces of CLR metadata and resources from the command line.

Notable scripts include:

* ``examples/dndump.py`` - dump PE and CLR information
* ``examples/dnstrings.py`` - inspect string data
* ``examples/dnguids.py`` - inspect GUID values
* ``examples/resources.py`` - inspect CLR resources
* ``examples/typeref-list.py`` - list type references

The usage patterns in those scripts mirror the API examples in the quickstart
and core concepts pages, so they are a good next stop when you want a concrete
workflow.
